Spatial data analysis

  • Spatial data analysis is the study of data that has a spatial component, such as location or geography.
  • Spatial data analysis can help us understand patterns and relationships in data that are influenced by location.

Example spatial data set: housing prices in A2

  • Suppose you choose to remain in Ann Arbor.
  • You may want to buy a house.
  • Where should you buy a house?

a2housing

a2housing contains information about housing prices in Ann Arbor over the past 4 years.

Basics

  • a2housing is a data frame with ~11k rows and 10 columns.
  • Each row is a house that was sold in Ann Arbor between 2021 and present.

Exploring the data

library(GGally)
a2housing |> select(where(is.numeric)) |> ggpairs()

Correlations

library(ggcorrplot)
corr <- a2housing |> dplyr::select(where(is.numeric)) |> cor(use = "pairwise.complete.obs")
ggcorrplot(corr)

Spatial data

  • Each row of a2housing has location, given by the address.
  • For example, the first row is a house at “1015 S Main St, Ann Arbor, MI 48104”.
  • Suppose we want to place these houses on a map…?

Geocoding

  • Geocoding is the process of converting addresses into geographic coordinates (latitude and longitude).
  • I geocoded these data for you using the US Census Geocoding API.
  • The lat and lon columns contain the latitude and longitude of each house.

Mapping the data

Problems with this plot

  • The points are not projected onto a map.
  • Not easy to see patterns or even localize the points to places in Ann Arbor.

sf package

  • To work with spatial data in R, we can use the sf package.
  • The sf package provides functions for reading, writing, and manipulating spatial data.

Convert to sf object

  • We can convert a2housing to an sf object using the st_as_sf() function.
  • We need to specify the coordinates and the coordinate reference system (CRS).

Coordinate reference system

  • The CRS specifies how the coordinates relate to locations on the earth.
  • The most common CRS is WGS 84, which is used by GPS and web mapping services.
  • The code for WGS 84 is 4326.
  • We will talk more about CRS next week.

Plotting sf objects

We can plot sf objects using geom_sf().

Providing context

Spatial autocorrelation

Everything is related to everything else, but near things are more related than distant things. - Tobler’s First Law of Geography:

  • Spatial autocorrelation is the correlation of a variable with itself through space.
  • In other words, it is the tendency for nearby locations to have similar values.

Visualizing spatial autocorrelation

Quantifying spatial autocorrelation

  • We can see that there is spatial autocorrelation in the housing prices.
  • “How correlated is my house price with my neighbor’s?”
  • To quantify this we need to locate the nearest neighbors of each house.

Nearest neighbors

  • We can use the st_nearest_feature() function from the sf package to find the nearest neighbor (in the dataset) of each house.

Census tracts

  • The US Census Bureau divides the country into small geographic areas called census tracts.
  • Census tracts are designed to be relatively homogeneous in terms of population characteristics, economic status, and living conditions.

Obtaining census tract data

  • Use the excellent tidycensus package to obtain census tract shapefiles.
  • Can also specific census variables (e.g. median hh income, B19013_001).

Plotting census tracts

Joining housing data to census tracts

  • If we want to summarize housing prices by census tract, we need to join the two datasets.
  • This is a new and special kind of join that we have not seen before: a spatial join.

Idea of spatial join

Spatial join

  • We can use the st_join() function from the sf package to perform a spatial join.
  • This will join the attributes of the census tracts to the housing data based on location.

  • Why did we get this error?
  • The two datasets have different coordinate reference systems (CRS).
