Measuring distances

Last lecture we learned how to measure distance in two ways:

  • Euclidean distance: \(\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}\)
  • Great-circle distance: shortest path along Earth’s surface.

Walking distance

Walking distance

To measure walking distance we need: - A dataset of streets, sidewalks, and paths; - A way to calculate shortest paths along the street network

Street network data

  • OpenStreetMap (OSM) is a free, open-source map of the world created by volunteers.
  • We can download street network data from OSM using the osmdata R package or other tools.

Walking from the diag to North Campus

  • Using a mapping application route from the Diag to North Campus is about 3.l km and takes about 39 minutes to walk.
  • How to find the best route?

Routing algorithm

  • We’ll use dodgr package to calculate shortest paths along the street network.
  • CS nerd stuff:
    • Technically this is solving a graph theory problem called “shortest path”.
    • Dijkstra’s algorithm is a classic algorithm for solving shortest path problems on graphs with non-negative edge weights.

Finding a shortest path using dodgr

# diag to north campus
diag = a2landmarks[3, c("lat", "long")]
north_campus = a2landmarks[4, c("lat", "long")]
# solve the routing problem; result is a list of vertices
dp <- dodgr_paths(a2graph_w, from = diag, to = north_campus)
verts <- dodgr_vertices(a2graph_w)
path1 <- verts [match (dp [[1]] [[1]], verts$id), ]
