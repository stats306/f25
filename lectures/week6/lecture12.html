Regression with interaction terms

  • Let’s consider the model \[ \mathrm{tmax} = \beta_0 + \beta_1 \times \mathrm{date} + \beta_2 \times \mathrm{city} + \epsilon \]
  • Here, city is a categorical variable with two levels: “Ann Arbor” and “Reno”.
  • The coefficient \(\beta_2\) measures the average difference in temperature between the two cities.

This tells us that Reno is on average about 4.8°C warmer than Ann Arbor, which is not surprising.

Understanding the model

Interpreting coefficients

  • When city is “Ann Arbor”, the model is \[ \mathrm{tmax} = \beta_0 + \beta_1 \times \mathrm{date} + 0 + \epsilon \]
  • When city is “Reno”, the model is \[ \begin{align} \mathrm{tmax} &= \beta_0 + \beta_1 \times \mathrm{date} + \color{red}{ \beta_2} + \epsilon\\ &= (\beta_0 + \color{red}{\beta_2}) + \beta_1 \times \mathrm{date} + \epsilon \end{align} \]
  • So \(\color{red} {\beta_2}\) is the difference in average temperature between Reno and Ann Arbor.

Adding interaction terms

  • Now consider the model \[ \mathrm{tmax} = \beta_0 + \beta_1 \times \mathrm{date} + \beta_2 \times \mathrm{city} + \beta_3 \times \mathrm{date} \times \mathrm{city} + \epsilon \]
  • The new term \(\beta_3 \times \mathrm{date} \times \mathrm{city}\) is an interaction term.
  • The coefficient \(\beta_3\) measures the difference in warming rates between the two cities.

Interpreting the model (math version)

  • When city is “Ann Arbor”, the model is \[ \mathrm{tmax} = \beta_0 + \beta_1 \times \mathrm{date} + 0 + 0 + \epsilon \]
  • When city is “Reno”, the model is \[ \mathrm{tmax} = \beta_0 + \beta_1 \times \mathrm{date} + \color{red}{\beta_2} + \color{blue}{\beta_3 \times \mathrm{date}} + \epsilon \] which can also be written as \[ \mathrm{tmax} = (\beta_0 + \color{red}{\beta_2}) + (\beta_1 + \color{blue}{\beta_3}) \times \mathrm{date} + \epsilon \]

Fixed-width data

  • This is an example of a fixed-width data file.
  • Unlike CSV, the columns are not separated by commas.
  • Instead, each column has a fixed width (number of characters).
