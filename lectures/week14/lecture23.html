NCAA data

Today we’re going to study data from the latest season of NCAA basketball:

Home field advantage

  • Last week we looked at a way to estimate home field advantage.
  • We reasoned that the margin of victory for the home team was a reasonable estimator, after controlling for team strength.
  • However, estimating team strength is difficult; it’s not directly observed, and there are many different ways to define/estimate it.
  • Today we’ll look at a different way of measuring HFA, it situations where the same teams play each other twice per season.

NCAA basketball data

  • In many NCAA conferences, each pair of teams plays twice:
    once at each team’s home court.
  • These paired games provide a natural experiment.
  • Because the teams are the same and games occur in both venues, differences in margins can be used to estimate the home-court advantage.

Home-court advantage

  • Assume the home team receives an additive boost of \(h\) points.
  • If a team wins by \(x\) at home, the expected neutral-court margin is \(x - h\).
  • If their neutral court margin is 0, then it’s 50/50 whether they win or lose.
  • We seek the value of \(x\) for which a neutral-court matchup becomes a coin flip: \[ \Pr(\text{A beats B on neutral court} \mid \text{A’s home margin was } x) \approx \tfrac12 . \]

Linking to Observable Outcomes

  • We do not observe neutral-court games between these pairs.
  • To work around this, compare A’s home game to B’s home game.
  • If A beats B by \(x\) at A’s home court, then on B’s court the expected margin is

\[ x - 2h, \]

since A loses its \(+h\) boost and B gains one.

\[ \begin{align} \Pr(\text{A beats B on neutral court} \mid x) \\ \approx \Pr(\text{A beats B on B’s court} \mid x + h). \end{align} \]

Interpretation

  • The total swing between the two venues is \(2h\).
  • A’s neutral-court advantage over B lies halfway between the two observed margins.
  • Thus:
    • A home margin of \(x + h\) corresponds to a neutral-court margin of \(x\).
    • A’s home boost relative to B is \(2h\), so the implied neutral-court advantage is \(h\).

Logistic Regression

Examples of binary outcomes

  • In a medical dataset, predicting if the patient is prone to diabetes or not.
  • If a given email is a Spam email or not.
  • If you take our nyc flights dataset, then will a flight is going to be late or not.

Linear vs. logistic regression

  • The linear model says:

    \[y = f(a_0 + a_1 x)\]

    for \(f(x)=x\).

  • For 0/1 outcomes, this won’t work. (Why not?)

  • Instead, let’s think about modeling the probability that \(y=1\):

    \[\text{Prob}(y=1) = \underbrace{f(a_0 + a_1 x)}_{(\text{some function of the covariates})}\]

The logistic function

What criteria should this function \(f\) have?

  • Its range needs to be \([0,1]\).
  • For “extreme” values of \(a_0 + a_1 x\) it should tend to zero or one.

Sigmoid function

A function which satisfies both the properties is the logistic function (a.k.a Sigmoid): \[f(x) = \frac{1}{1 + e^{-x}} =\frac{e^x}{1 + e^{x}} .\]

\[f(a_0+a_1x) = \frac{e^{a_0+a_1x}}{1 + e^{a_0+a_1x}} .\]

Log-odds, logit, and sigmoid

  • The odds of an event with probability \(p\) is defined as

    \[\text{odds} = \frac{p}{1-p}.\]

  • The logit function is the function that maps a probability \(p\) to its log-odds:

    \[\text{logit}(p) = \log\left(\frac{p}{1-p}\right).\]

  • The sigmoid function is the inverse of the logit function: sigmoid(logit(p)) = p.

Logistic vs. linear model

Estimating logistic regression in R

  • We use the glm() function, which stands for “generalized linear model”.
  • Basic format: glm(y ~ x, data=., family="binomial")
  • Make sure you specify family="binomial"! Otherwise you’re getting linear regression!

Summarizing

  • Linear regression: \[\underbrace{\mathbb{E}(Y | X = x)}_{\text{conditional mean}} = ax +b\]
  • Logistic regression: \[\underbrace{\mathrm{logit}[\mathbb{P}(Y | X = x)]}_{\text{conditional prob.}} = ax +b\]

Computing HCA

Our logistic regression model is

\[\log \left( \frac{p}{1-p} \right) = a_0 + a_1 x.\]

If \(p=1/2\) then the LHS is zero, and we get simply \(h = -a_0/a_1\).
